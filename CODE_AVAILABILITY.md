# Code Availability

The implementation and analysis code supporting this study are publicly
available at:

https://github.com/Kevinnnnn13/ai-scientist

The repository includes the scientific planning agent, evidence-verification
and release-authorization modules, robustness experiment configurations,
statistical analysis utilities, manuscript-building scripts, figure-generation
code, and frozen plotting inputs. It does not contain API credentials, user
data, or restricted materials. Researchers reproducing the workflow must
provide their own credentials through environment variables as described in
the repository documentation.

The released version described in the manuscript is available from the
`v1.0.0` tag.
